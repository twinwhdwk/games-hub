# 🎓 학습 게임 허브 (games-hub)

초등학생(3~6학년)을 위한 교과 연계 미니게임 모음집입니다. GitHub Pages로 배포되어 별도 설치 없이 브라우저에서 바로 즐길 수 있습니다.

🔗 **플레이**: https://twinwhdwk.github.io/games-hub/

## 🎮 게임 목록

| 게임 | 과목 | 형식 |
|---|---|---|
| 🤖 트랜스포머 구구단 대작전 | 수학 | 슈팅/디펜스, 보스전 |
| 🧊 분수 계단 탈출 | 수학 | 5단계 던전, O/X 퀴즈 |
| ⚔️ 수양대군의 영어 정벌 | 영어 | 타워디펜스, 10단계 |
| 🏯 한국사 시간탐험대 | 사회(역사) | 시대별 4지선다 |
| 🚀 총알 피하기 | 과학·역사·국어·수학·지리 | 아케이드 + 퀴즈 |
| 🧭 지식 탐험대 | 사회·과학·국어·영어 | 4지선다 |
| 🃏 짝꿍 찾기 | 국어·영어·과학·사회 | 카드 매칭 |
| 🪄 빈칸 마법사 | 국어·영어 | 빈칸 채우기 |

📔 **성장 일지**: 캐릭터 성장, 과목별 학습 레벨, 게임별 기록, 오답노트 현황을 한눈에 확인.

## ✨ 학습 허브 시스템 (`shared.js`)

모든 게임이 공유하는 학습 관리 시스템입니다.

- **프로필**: 이름 기반 간단 로그인, 여러 사용자(자녀) 전환 가능
- **과목별 학년(3~6학년) 자동 조절**: 정답률에 따라 난이도가 자동으로 올라가거나 내려갑니다
- **오답노트(스페이스드 리피티션)**: 틀린 문제는 다음 플레이에 우선 출제되고, 연속 정답 시 마스터 처리
- **캐릭터 성장**: EXP/레벨 시스템, 픽셀아트 캐릭터(머리·옷·모자·무기·펫·피부 6슬롯, 34종 아이템)
- **업적 시스템**: 게임별 특정 조건(퍼펙트 클리어, 콤보 등) 달성 시 전용 아이템 해금

## 📚 콘텐츠 기준

문제 데이터(`data/*.json`)는 **2022 개정 교육과정**(2026년 기준 전 학년 적용)을 바탕으로 제작되었습니다.

- `data/question_bank.json` — 지식탐험용 4지선다 문제 (사회/과학/국어/영어, 학년별)
- `data/matching_bank.json` — 짝꿍찾기용 매칭 쌍 (국어/영어/과학/사회)
- `data/blank_bank.json` — 빈칸마법사용 빈칸 문제 (국어 맞춤법/영어 스펠링)

## 🛠 기술 스택

순수 HTML/CSS/JavaScript (프레임워크 없음), `localStorage` 기반 데이터 저장. 모든 페이지는 단일 파일로 구성되어 있으며 `shared.js`만 공유합니다.

## 📂 구조

```
games-hub/
├── index.html              # 허브 메인 (게임 목록, 캐릭터 패널)
├── shared.js               # 학습 허브 공통 시스템
├── 성장일지.html            # 학습 대시보드
├── [게임명].html × 8        # 개별 게임
└── data/
    ├── question_bank.json
    ├── matching_bank.json
    ├── blank_bank.json
    └── scripts/             # 데이터 생성용 스크립트
```
